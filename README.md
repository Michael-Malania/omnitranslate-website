# OmniTranslate Live — Official Showcase & Interactive Landing Page

The official website and interactive simulation showcase for **OmniTranslate Live** — real-time AI audio and voice translation for Mobile (Android & iOS) and Desktop (Windows & Mac).

---

## 🌟 Features Highlighted

1. **Dual Platform Capabilities**:
   - **Mobile App**: Internal hardware audio loopback capture (translating YouTube videos, TikTok clips, and Telegram voice notes), floating frosted glass HUD, dynamic speaker voice timbre.
   - **Desktop App**: Frameless floating circular microphone widget, instant **`🎙️ MIC ⇄ 🔊 SYS`** dual-mode toggle, virtual cable routing for Zoom / Google Meet / Teams / Discord, and automatic voice pass-through unmuting.

2. **Interactive Live Translation Playground**:
   - Real-time simulated scenarios (YouTube Tech Review, Telegram Voice Note, Zoom Business Meeting, TikTok Street Clip).
   - Dynamic male & female pitch detection demonstration.

3. **Multi-Store Download Hub**:
   - Links to Apple App Store, Google Play, Android APK, and Windows Native Desktop.

4. **Pricing Tiers**:
   - Interactive monthly and annual pricing switcher with discount toggles.

---

## 🚀 Running Locally

No npm build step is required! You can open `index.html` directly or serve with any static HTTP server:

```bash
# Using Python
python -m http.server 8080

# Or using npx serve
npx serve .
```

Then visit [http://localhost:8080](http://localhost:8080) in your browser.
